# Academics-AIML-Projects

Coursework and academic data science / ML projects from my postgraduate studies in Data Science & Business Analytics, 2023-2025, archived here for reference.

Each folder was originally a separate repository and was imported here with its commit history. Descriptions below are taken from each project's original README.

| Project folder | Description (from original README) | Main tools |
|---|---|---|
| [Diabetes-Classification](Diabetes-Classification/) | Predict whether or not a patient has diabetes, based on diagnostic measurements from the Pima Indians Diabetes dataset. | Python, Jupyter, pandas, scikit-learn, XGBoost, matplotlib, seaborn |
| [Health-Care-Insurance-Cost-Prediction](Health-Care-Insurance-Cost-Prediction/) | A model for predicting individual health insurance costs from factors such as age, medical history, lifestyle choices, and regional trends. | Python, Jupyter, pandas, scikit-learn, XGBoost, statsmodels, factor_analyzer |
| [Statistical-Methods-for-Decision-Making](Statistical-Methods-for-Decision-Making/) | Statistical methods for decision making: an Austo Motor Company marketing-campaign problem and a Go Digit dataset analysis problem. | Python, Jupyter, pandas, matplotlib, seaborn |
| [Time-Series-Forecasting](Time-Series-Forecasting/) | Forecasting wine sales for ABC Estate Wines from historical monthly sales data. | Python, Jupyter, pandas, statsmodels (exponential smoothing, ARIMA), scikit-learn |
| [Machine-Learning](Machine-Learning/) | Election exit poll prediction and U.S. presidential inaugural speech analysis using machine learning. | Python, Jupyter, pandas, scikit-learn, XGBoost, NLTK, WordCloud |
| [Predictive-Modelling](Predictive-Modelling/) | Two parts: linear regression to forecast computer user-mode time, and classification of contraceptive use among women. | Python, Jupyter, pandas, scikit-learn, statsmodels |
| [Recommending-ways-to-increase-revenue-of-a-Grocery-Store](Recommending-ways-to-increase-revenue-of-a-Grocery-Store/) | Ideas for how a grocery shop can boost sales through combo and discount offers, based on a study of Point of Sale (POS) data. | KNIME (market basket analysis), Tableau |
| [Understanding-Customers-Buying-Patterns-for-an-Automobile-Parts-Manufacturer](Understanding-Customers-Buying-Patterns-for-an-Automobile-Parts-Manufacturer/) | Find the buying patterns of an automobile part manufacturer's customers from 3 years of transaction data and recommend marketing strategies per customer segment. | KNIME, Tableau |
| [Visualizing-Insurance-Claims-using-Tableau](Visualizing-Insurance-Claims-using-Tableau/) | Interactive Tableau dashboards giving high-level insights to an insurance company's CEO. | Tableau |
| [E-Commerce-Revenue-Management](E-Commerce-Revenue-Management/) | Determine which region has the highest sales volume, which products sell the most, and the revenue generated by the company and the brands on its platform. | Python, Jupyter, pandas, Plotly, matplotlib, seaborn |
| [Online-retail-Orders-Analysis](Online-retail-Orders-Analysis/) | Questions answered on an online retail company's "orders" database to support data-driven decisions. | SQL |

Note: the original SQL script for Online-retail-Orders-Analysis is not included in this archive because it contained sample customer names, emails, and addresses.
